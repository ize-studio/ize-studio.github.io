About

Ize Studio is a small studio for writing, tools, experiments, and objects.

Ize Studio is an English-language archive for essays, fiction, reading notes, writing tool reflections, and project records.

It gathers fiction alongside notes on books, writing instruments, e-ink tools, software, and the broader practice of building tools for thoughtful composition.

The site is not limited to Ize Compose. It is a home for connected work: essays, fiction, reading systems, e-ink experiments, project documentation, and small objects prepared over time.
